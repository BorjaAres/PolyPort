Quick start
  1. Open a model in Tripo Studio.
  2. Wait for the 3D viewer to finish loading.
  3. Loaded model resources are detected automatically. If needed, select Find models in viewer.
  4. Choose a file, format and size.

Capture and conversion happen locally in this tab. PolyPort adds no usage quotas.
